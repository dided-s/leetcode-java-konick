После каждого хода сумма оставшихся камней не меняется, меняется только то, 
какой префикс уже “съеден”. 
Поэтому каждый ход можно описать не количеством камней, а индексом u 
в массиве префиксных сумм pre, и за ход игрок получает pre[u] очков

1. сначала строим pre[i] = stones[0] + ... + stones[i];
2. затем игроки по очереди выбирают допустимые индексы;
3. выбранный индекс означает: “я забираю сумму до этого места”

### Почему нужен DP
В таких играх выгодно хранить не сами очки игроков, а разницу между текущим игроком и соперником. 
Тогда состояние f[i] означает: какую максимальную разницу можно получить, 
если сейчас можно выбирать индекс начиная с i

Для каждого i есть два варианта:

1. не брать i, тогда ответ такой же, как для i+1;
2. взять i, тогда текущий игрок получает pre[i], 
а дальше соперник играет оптимально, поэтому из результата нужно вычесть f[i+1]

$f[i]=max(f[i+1],pre[i]−f[i+1])$

f[i] зависит от f[i+1], значит считать нужно с конца массива к началу. 
База проста: если осталась последняя позиция, 
то можно сразу забрать всё оставшееся, поэтому f[n-1] = pre[n-1]

Почему ответ f[1]
Это важный момент: в первой ход Alice нельзя взять индекс 0, 
потому что по условию первый ход должен объединять больше чем одну кучу. 
Поэтому стартовое состояние — не f[0], а f[1]

DP здесь отвечает на вопрос: если я сейчас стою в позиции i, что выгоднее — пропустить этот индекс или взять его прямо сейчас и заставить соперника играть хуже?
